# Junie Extension Creator

Use this skill when adding or changing a local native Junie extension source.

Read `../nddev-builder/references/extensions-marketplace.md` first.

Create a valid local marketplace source tree, but do not fabricate installed
extension state without a documented noninteractive Junie install path.
