# Junie Config Creator

Use this skill when creating or changing managed Junie `config.json` content.

Read `../nddev-builder/references/native-path-model.md` and
`../nddev-builder/references/config.md` first.

Create only documented Junie config fields, keep every path target-owned, and do
not add provider credentials, proxies, personal settings, or unknown keys.
